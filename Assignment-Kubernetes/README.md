# Kubernetes Deployment - Student Academic Platform

## 1. Project Overview

This project demonstrates container orchestration using Kubernetes.
The Student Academic Platform is a Flask application packaged in a
Docker container and deployed to a Kubernetes cluster using Minikube.

## 2. Technologies Used

- Python
- Flask
- Docker
- Kubernetes
- Minikube
- kubectl
- AWS EC2
- Git and GitHub
